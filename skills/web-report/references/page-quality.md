# 页面质量清单

## 排版

- 单栏内容最大宽度 720–840px，居中；两侧留白不小于 16px。
- 字号：正文 15–17px，行高 1.6–1.75；标题层级最多 3 级，不要靠字号堆叠制造层次。
- 间距用 4/8 的倍数；区块之间 32–48px，卡片内边距 16–24px。
- 数字使用等宽或 `font-variant-numeric: tabular-nums`，右对齐，单位与数值分开。
- 颜色只用设计系统变量；一个页面最多一个强调色。

## 结构

- 第一屏必须出现：标题、时间范围、一句话结论、核心 KPI。
- 每个图表上方有标题，下方有读数说明或数据口径；不要让读者自己猜。
- 表格有表头、对齐方式一致；数值列右对齐，文本列左对齐。
- 长页面在顶部给一个简短目录（锚点链接），移动端可折叠。

## 移动端

- 在 375px 宽度下检查：无横向滚动、卡片单列、图表不变形、按钮/链接可点。
- 表格外层加 `overflow-x:auto`，并给出“左右滑动查看”的提示。
- 不使用固定像素宽度的大图；SVG 用 `viewBox` + `width:100%`。

## 可访问性

- `<html lang="zh-CN">`；每个 `<section>` 有可读标题。
- 图片/图表有 `aria-label` 或 `<title>`；装饰性元素 `aria-hidden="true"`。
- 正文与背景对比度 ≥ 4.5:1；涨跌色同时配文字（如“+12%”“-3%”）。
- 链接文字能独立表达含义，不用“点击这里”。

## 打印

- 用 `@media print` 去掉阴影、固定定位和深色大面积背景。
- 每个主要区块尽量不被分页截断：`break-inside: avoid`。
- 打印时保留 URL 或数据口径说明。

## 交付前自检

- [ ] 没有 `http(s)://` 外链、没有 `/a/_shared/` 引用
- [ ] 样式、脚本、图表、图片全部内联
- [ ] 有 `<html lang>`、charset、viewport
- [ ] 375px 下无横向溢出
- [ ] 自检问题已全部修复
- [ ] 单文件小于配置上限（默认 200KB）
- [ ] 预览地址可打开，首屏能读到结论
