# Frontend Design

把页面当成一个有明确客户、明确受众、明确任务的设计项目，而不是把组件库默认样式拼起来。

## 何时不用本技能

- 数据报告、周报、统计看板、单页数据分析 → 用 `web-report`，它带数据口径与图表规范。
- 任务本质是写内容而不是做视觉 → 直接写，不要套设计流程。

## 先定 brief

在写 HTML 之前，先确认三件事：

1. **这个页面是什么**：产品、报告、作品集、活动页、文档？
2. **给谁看**：客户、同事、招聘方、投资者？
3. **第一眼要完成什么任务**：理解结论、产生兴趣、提交表单、下载报告？

如果用户没有说清，先给一个具体提案（主题 + 受众 + 首要任务），确认后再做；不要用“通用现代风”代替判断。

## 两遍法

### 第一遍：写设计计划

用几行文字定下来：

- **颜色**：4–6 个命名 hex 值，写清底色、表面色、正文色、弱化色、强调色。强调色只用一个。
- **字体**：1–2 个字体家族，写清标题和正文各自的角色；中文优先系统字体栈。
- **布局**：用一句话和 ASCII 线框比较 2–3 种结构，选定一种；写清左对齐/居中/两端对齐。
- **原则**：这个页面为什么不像模板？哪一个是“记忆点”？

### 第二遍：对照 brief 批判

问自己：如果换一个同类客户，这个方案是不是也成立？如果答案是“是”，说明它还是默认方案，回到第一遍改。

只保留一个大胆的选择，其余部分保持安静和克制。

## 本项目硬约束

- 成品是**单文件 HTML**，样式、脚本、图表、图片全部内联。
- 不引用任何 `http(s)://`、CDN、外链字体、外链图片；不用 `<script src>`。
- 必须有 `<html lang="zh-CN">`、`<meta charset>`、viewport。
- 375px 宽度不横向溢出；表格放可滚动容器，图表用 `viewBox`。
- 正文对比度 ≥ 4.5:1；涨跌不只靠颜色，配文字或符号。
- 单文件小于配置上限（默认 200 KB）。
- 打印可读：避免大面积深色背景，关键内容不依赖 hover。

设计系统文件在 `data/artifacts/_shared/`：

- `tokens.css`：颜色、间距、字号、圆角变量；
- `base.css`：卡片、表格、按钮、表单、callout 等基础样式；
- `gallery.html`：落地页、报告、文章、作品集、表单等页面类型示例；
- `charts.js`：只有确实需要图表时才读，函数源码内联进 `<script>`。

先用 `fs_read` 读，再把需要的规则**内联**进成品页；不要在成品里引用 `_shared`。

## 避免这些默认

下面这些不是绝对禁止，但如果没有为当前 brief 辩护，就不要用：

- 米白背景 + 高对比衬线标题 + 陶土色强调（AI 生成页面的常见组合）；
- 近黑背景 + 单一荧光绿/朱红强调；
- 所有内容都切成同样的圆角卡片，阴影和圆角没有层级；
- 每个标题上方都加全大写小标签（eyebrow）；
- 用小号等宽字体堆元数据，用 `·` 拼接；
- 按钮和链接统一加 `→`；
- 紫色渐变、Inter 字体、统一的 16px 圆角。

## 排版

- 正文 15–17px，行高 1.6–1.75；中文正文行高可略高。
- 标题层级最多 3 级，靠字号、字重和间距建立层次，不要靠颜色堆叠。
- 正文行宽控制在 65–80 字符；中文单栏最大宽度 720–840px。
- 数字用 `font-variant-numeric: tabular-nums`，数值列右对齐。
- 一个页面最多一个强调色；语义色（成功/警告/危险）只在有语义时用。

## 结构

- 边框、分割线、编号、标签都应该编码信息，而不是装饰。
- 只有内容真的是序列（步骤、时间线）时才用 01/02/03。
- 首屏必须让读者读到结论或价值主张，不要用大图和口号占满。
- 长页面在顶部给简短目录，移动端可折叠。
- 表单字段分组，错误提示写清“哪里错、怎么改”。

## 动效

- 只保留一个编排好的时刻（首屏加载或一次展开），不要每个 section 都 fade-and-slide。
- 尊重 `prefers-reduced-motion`。
- 动效要回答用户动作（打开、展开、确认），而不是自嗨。

## 文案

- 主动语态；按钮写清点击后发生什么（“保存修改”，不是“提交”）。
- 同一个动作在全流程用同一个词：按钮叫“发布”，提示就叫“已发布”。
- 错误不道歉、不模糊：说明发生了什么、下一步怎么做。
- 空状态是行动邀请，不是一句“暂无数据”。

## 交付前自检

- [ ] 没有外链资源，没有 `/a/_shared/` 引用
- [ ] 有 `<html lang="zh-CN">`、charset、viewport
- [ ] 375px 下无横向滚动
- [ ] 首屏能读到结论或价值主张
- [ ] 强调色只有一个，颜色有明确角色
- [ ] 自检问题已修复，预览地址可打开
- [ ] 单文件小于配置上限
